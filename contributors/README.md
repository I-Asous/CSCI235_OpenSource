# Contributors

Every student who has had a pull request merged into this library has a file here.

To add yourself, follow [Lab 2](../docs/labs/02-first-pull-request.md). In short:

1. Copy [`_TEMPLATE.md`](_TEMPLATE.md) to `contributors/<your-github-username>.md`. The file name must match your username exactly.
2. Fill it in. CI checks the format, so a typo will show up as a red ❌ on your PR.

Each person edits only their own file, so nobody's PR conflicts with anyone else's.
